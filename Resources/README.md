# 🗺️ Python Web Bootcamp - Roadmaps & Resources

Welcome to the Resources directory! This folder contains the official roadmaps and reference documents that guide my learning journey. Below is a summary of the concepts and skills acquired in each unit.

## 📘 Unit 1: Environment Setup & Version Control
The first unit focused on establishing a professional development environment and mastering version control. Key concepts mastered include:
* **Command Line Fundamentals:** Navigating the file system and executing basic CLI operations (such as `cd`, `mkdir`, `cp`, `rm`, and `nano`) confidently from the shell[cite: 1].
* **Python Environment & Packages:** Isolating projects using virtual environments (`venv`) and managing package dependencies with `pip`[cite: 1].
* **Git Fundamentals:** Understanding the repository lifecycle (Working Directory, Staging Area, Local Repository) and tracking changes with commands like `git add`, `git commit`, and `git status`[cite: 1].
* **GitHub & Remote Repositories:** Hosting code in the cloud, syncing local work with remotes using `git push` and `git pull`, and configuring files like `.gitignore` and `README.md`[cite: 1].
* **Branching & Collaboration:** Creating branches, integrating history with merges, and understanding collaborative tools like Pull Requests[cite: 1].

## 📙 Unit 2: Python Core & Object-Oriented Programming
The second unit dove deep into Python programming, moving from foundational syntax to advanced architectural concepts. Key concepts mastered include:
* **Python Fundamentals & Control Flow:** Working with variables, data types, type casting, arithmetic/logical operators, and controlling execution flow using `if-elif-else`, `match-case`, and `for/while` loops[cite: 2].
* **Data Structures & Strings:** Manipulating collections using Lists (indexing, slicing, and methods like `append`), and formatting/processing strings dynamically[cite: 2].
* **Functions & Scope:** Building reusable functions, understanding parameters, and managing variable scope (Namespaces)[cite: 2].
* **File Handling & Formats:** Reading, writing, and appending files using `Pathlib` and context managers (`with open`), alongside processing structured data formats like `CSV` and `JSON`[cite: 2].
* **Exception Handling:** Building robust applications by catching and handling errors using `try-except-else-finally` blocks, and creating custom exceptions[cite: 2].
* **OOP Foundations:** Designing classes, initializing objects via `__init__`, defining instance/class attributes and methods, and understanding object state and collections[cite: 2].
